# ময়মনসিংহ মেট্রোপলিটন ওপেন স্কাউট গ্রুপ

GitHub Pages-ready website.

## Files
- `index.html` — মূল portfolio website এবং একই পেজের ভিতরের ভর্তি ফরম
- `Code.gs` — Google Apps Script backend source (GitHub Pages নিজে এটি চালায় না)
- `.nojekyll` — GitHub Pages static publishing helper

## GitHub Pages
1. এই ফোল্ডারের সব ফাইল repository-এর root-এ upload করুন।
2. Repository → Settings → Pages
3. Build and deployment-এ `Deploy from a branch` নির্বাচন করুন।
4. Branch: `main`, Folder: `/ (root)` নির্বাচন করে Save করুন।
5. কিছু সময় পর `Visit site` দিয়ে website দেখুন।

ভর্তি ফরমটি `index.html`-এর মধ্যেই আছে এবং বর্তমানে Google Apps Script endpoint-এ submission পাঠানোর জন্য configured।
